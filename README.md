# Practical Mac Tools site

Static, no-cost GitHub Pages site for the three public Mac apps. The main copy is English. Each app's `2026Oct_Portfolio` campaign token reuses the provider token generated in App Store Connect, and the published Mac URLs were validated in the China-region browser environment.

Source-language stage: the site currently has no locale selector or translated pages. The product portfolio's 36-language target remains separate from App Store metadata, screenshots, and these marketing pages. If this site becomes a maintained product surface, expand its localized copy under the established 36-language process after the English positioning is stable.

Pages deliberately include no ad scripts, cookies, or custom analytics. GitHub Pages hosting behavior is governed by GitHub's own policies.
