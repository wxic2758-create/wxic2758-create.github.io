Remote files

Download files from your SFTP server on Mac

When the file you need lives on a VPS or NAS, a short browse-and-download workflow can be easier than remembering its full remote path.

1. Connect to a server you control

In CloudBridge, add the server address, port, username, and password for an SSH/SFTP server you are authorized to use. Confirm the host identity carefully on first connection. CloudBridge connects directly to that server without a CloudBridge account or hosted relay.

2. Find and inspect the right file

Browse the remote folders or search within the current directory. For a supported file, use Quick Look to inspect it before downloading. Preview support depends on the file type and macOS preview capabilities.

3. Download and verify

  • Choose a file or folder, then start the download to your selected local directory.
  • Use the download list to follow progress or pause, resume, cancel, or retry as needed.
  • Reveal a completed download in Finder and check that it is the version you wanted.

Keep backups and access controls appropriate for your server. CloudBridge is a file-access tool, not a backup service.
