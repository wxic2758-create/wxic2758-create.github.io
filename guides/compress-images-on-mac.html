Image workflow

Compress a batch of images on Mac

The useful result is a smaller file that still looks right at the size where it will be used. Check both, especially when preparing several images for a website, email, or social post.

1. Group files by destination

Keep website graphics, photographs, and screenshots in separate groups when they have different quality needs. Preserve an untouched copy of the source files so you can compare results or try different settings.

2. Compress locally

Add a batch to CompressBox, choose the image settings that fit the group, and run compression on your Mac. The app supports PNG, JPEG, WebP, BMP, ICO, and GIF images. It also has a separate video workflow for MP4, MOV, and M4V.

3. Inspect the output

  • Compare file size before and after. A smaller result is only useful if it still suits the destination.
  • Check fine text, edges, gradients, and detailed photos at the display size that matters.
  • If detail is lost, use a gentler setting or keep the original for that file.

4. Export the version you want to share

Use the output files after the visual check. For a web project, test them in the actual page layout; for a client handoff, keep the original set alongside the compressed deliverables.
